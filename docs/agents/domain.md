# Domain docs

**Single-context.** One `CONTEXT.md` and one `docs/adr/` at the repo root — no `CONTEXT-MAP.md`, no per-subdirectory contexts.

- Read `CONTEXT.md` before using any domain term (Wing, Graduation, Pipeline, Sleeve) — don't infer meaning from the word alone.
- Read `docs/adr/` in numeric order for prior architectural decisions before proposing something that might contradict one.
