What this mirror includes

In scope

  • The Testing engine: position/leg modeling, strike selection, backtest driver, MCPT/PBO, walk-forward validation
  • The graduation mechanism (frozen snapshots, dependency-closure resolution, zero live coupling)
  • The Shadow mechanism: execution math, capture-fraction ledger, read-only broker clients
  • Ingestion: scraping + schema + storage code
  • Architecture decisions (docs/adr/) and the full test suite behind all of the above

Deliberately excluded

  • Every strategy implementation (signal, entry/exit logic, tuned parameters)
  • Every backtest result — no Sharpe, no P&L, no p-values tied to a real run
  • Market data of any kind
  • Anything already graduated to Shadow or a live Pipeline
  • Deploy/composition scripts tied to a specific live deployment
testing/strategies/toy_example/ is a synthetic fixture used only by the graduation-mechanism tests — not a real strategy, and unrelated to anything actually researched in the private repo this was mirrored from.
